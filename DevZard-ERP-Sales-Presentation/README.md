# DevZard School ERP — Sales Presentation

Independent, offline sales deck for school owners, principals, and education groups.

This folder is **not** part of the running ERP. It does not call APIs, open the school website, or load live data.

## Open the deck

1. Copy this folder anywhere (USB, laptop, GitHub checkout).
2. Open `index.html` in Chrome, Edge, or Safari.
3. Present full screen (`F11` or browser full screen).

No install. No internet. No login.

## Controls

- **Next:** Right arrow, Space, Page Down, or on-screen Next
- **Back:** Left arrow, Page Up, or on-screen Back
- **Jump:** Home / End
- **Swipe** on a tablet
- **Print / PDF:** Browser print — each slide is one page

## Contents

28 slides covering problem, solution, all role portals, fees workflow, admissions, appointments, attendance, results (including Final Term countdown), timetable, homework, announcements, multi-campus, module switches, access model, and a demo CTA.

Visuals are static mockups and generated brand images. Names such as *Northbridge Academy* are sample only.

## CTA

The closing “Book a Demo” control is visual only. It is not a link.

## Do not

- Point this deck at a live `/app` or website URL
- Mix these files into the Java/React build
- Treat mock numbers as a customer’s real census
